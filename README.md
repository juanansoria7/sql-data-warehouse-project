# sql-data-warehouse-project
Construir un moderno data wherehouse con SQL, incluyendo proceso de ETL, modelado de datos y analítica

Este proyecto muestra una solución completa de data warehousing y analítica: desde la construcción del data warehouse hasta la obtención de conclusiones útiles para el negocio. Está planteado como proyecto de portfolio y aplica buenas prácticas habituales en ingeniería y análisis de datos.

---

## Requisitos del proyecto

### Construcción del data warehouse (ingeniería de datos)

#### Objetivo
Desarrollar un data warehouse moderno con SQL Server que consolide los datos de ventas y permita hacer informes analíticos y tomar decisiones con información fiable.

#### Especificaciones
- **Fuentes de datos**: importar datos de dos sistemas origen (ERP y CRM), que se entregan como archivos CSV.
- **Calidad de datos**: limpiar y corregir los problemas de calidad antes del análisis.
- **Integración**: unir ambas fuentes en un único modelo de datos, fácil de usar y pensado para consultas analíticas.
- **Alcance**: trabajar solo con el conjunto de datos más reciente; no hace falta guardar histórico.
- **Documentación**: documentar con claridad el modelo de datos, tanto para los responsables de negocio como para los equipos de analítica.

---

### BI: analítica e informes (análisis de datos)

#### Objetivo
Desarrollar análisis basados en SQL que den información detallada sobre:
- **Comportamiento de los clientes**
- **Rendimiento de los productos**
- **Tendencias de ventas**

Con estos análisis, los responsables del negocio disponen de las métricas clave para tomar decisiones estratégicas.
